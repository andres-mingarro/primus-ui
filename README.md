# Primus UI

Copy-paste component library for **Next.js** and **Drupal SDC**.

Each component ships in three flavors:

- React with Tailwind CSS
- React with plain CSS (no Tailwind dependency)
- Drupal Single Directory Component (SDC)

## Usage

Pick a component, copy the version you need, drop it in your project.

## Development

```bash
cd landing
npm install
npm run dev
```

## Structure

```txt
components/     # Library components (copy these)
landing/        # Showcase & docs site
```
